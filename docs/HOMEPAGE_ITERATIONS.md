## 宽屏导航与作品入口：20 轮增量优化

1. **定位冲突**：移除固定导航上的内容入场类，避免动画覆盖 `translateX(-50%)` 后整块偏到屏幕右侧。
2. **网格对齐**：导航宽度改为 `min(100% - 3rem, 1280px)`，与主页内容区共享左右边界。
3. **容器形态**：把小胶囊升级为横向 Command Rail，让宽屏首屏形成稳定的顶、左、右三条基线。
4. **信息分区**：采用“身份 / 当前状态 / 导航动作”三段结构，填充空间但不堆砌菜单。
5. **身份说明**：品牌下增加 `AI Agent Engineer`，首次访问不再只看到难以理解的用户名。
6. **状态信号**：新增 `Agent systems · active` 绿色状态点，为 Agent 工程师身份提供运行态语义，且不暗示商务可用性。
7. **方法标签**：以 `Build · Verify · Ship` 明示工程价值观，与主页技术定位互相呼应。
8. **主次链接**：GitHub 与 Trace Lab 保持轻量，博客使用实色主按钮承接核心内容转化。
9. **链接顺序**：把站内实验放在博客主入口前，使浏览路径从“了解能力”自然过渡到“阅读内容”。
10. **滚动态**：滚动后导航靠近顶部并提高背景实度，长页面阅读时更省空间、更清晰。
11. **性能控制**：滚动监听采用 passive listener + `requestAnimationFrame`，避免高频样式抖动。
12. **桌面反馈**：品牌图标、菜单与 CTA 使用不同强度的微动效，突出层级而非全体同时晃动。
13. **焦点可见**：沿用统一 `focus-visible`，确保键盘操作时导航与作品入口均有明确焦点。
14. **语义修复**：品牌由普通容器改为首页链接，导航继续使用原生 `nav` 与清晰的 ARIA 标签。
15. **作品可达**：Selected Works 三项由静态块改为真实链接，不再让可点击外观变成无效区域。
16. **方向提示**：作品入口加入轻量方向箭头，分别提示跳转和页内下钻。
17. **触控布局**：手机不再隐藏全部导航，只隐藏低优先级 GitHub，保留 Trace Lab 与博客入口。
18. **窄屏密度**：移动端缩小身份副标题、圆角和内边距，维持 58px 可辨识导航高度。
19. **回归防护**：校验脚本新增规则，禁止固定导航再次接入会覆盖定位的 reveal class。
20. **维护说明**：把问题根因、设计决策和断点策略写入本文档，避免后续只凭截图反复调参。
