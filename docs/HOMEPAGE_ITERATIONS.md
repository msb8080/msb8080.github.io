# 个人主页 10 轮迭代记录

日期：2026-09-05

1. **入口可信度**：检查主页外链，移除已无法解析的旧作品集地址，保留可访问的博客、GitHub 与 OmniAgent。
2. **个人定位**：从泛化的“AI 后端 / RAG”收敛到 Java、Spring AI、Agent Harness、评测与可靠 Agent 系统。
3. **首屏层级**：重写 Hero 摘要、状态文案和数据卡，让访客先理解身份，再进入内容与项目。
4. **原创互动**：新增 Agent Trace Lab，以任务脉冲表现 Planner、Context、Tools、Memory 与 Verifier 的协作闭环。
5. **交互可用性**：加入巡航、聚焦、派发任务和重置操作，Canvas 同时支持鼠标、触摸与键盘。
6. **视觉辨识度**：延续深紫品牌色，但用青色轨迹、运行图和差异化项目卡替代参考站的数字弹球表达。
7. **Bento 重排**：修复浅底白字问题，将项目卡重新组合为 6 + 3 + 3 + 6 的稳定密铺结构。
8. **响应式优化**：手机端改为单列阅读，数据卡保持三列，轨迹控制改为 2 × 2，消除横向溢出。
9. **性能与降级**：删除 Tailwind CDN、GSAP 和 ScrollTrigger 依赖，使用原生 IntersectionObserver 与 Canvas；限制 DPR、离屏暂停，并尊重减少动态效果设置。
10. **可访问性与维护**：补充跳转链接、焦点样式、ARIA、外链安全属性、Open Graph 信息，并增加零依赖自动校验脚本。

验证命令：`npm run check`

## 宽屏导航与作品入口：20 轮增量优化

1. **定位冲突**：移除固定导航上的内容入场类，避免动画覆盖 `translateX(-50%)` 后整块偏到屏幕右侧。
2. **网格对齐**：导航宽度改为 `min(100% - 3rem, 1280px)`，与主页内容区共享左右边界。
3. **容器形态**：把小胶囊升级为横向 Command Rail，让宽屏首屏形成稳定的顶、左、右三条基线。
4. **信息分区**：采用“身份 / 当前状态 / 导航动作”三段结构，填充空间但不堆砌菜单。
5. **身份说明**：品牌下增加 `AI Agent Engineer`，首次访问不再只看到难以理解的用户名。
6. **状态信号**：新增 `Agent systems · active` 绿色状态点，为 Agent 工程师身份提供运行态语义，且不暗示商务可用性。
7. **方法标签**：以 `Build · Verify · Ship` 明示工程价值观，与主页技术定位互相呼应。
8. **主次链接**：GitHub 与 Trace Lab 保持轻量，博客使用实色主按钮承接核心内容转化。
9. **链接顺序**：把站内实验放在博客主入口前，使浏览路径从“了解能力”自然过渡到“阅读内容”。
10. **滚动态**：滚动后导航靠近顶部并提高背景实度，长页面阅读时更省空间、更清晰。
11. **性能控制**：滚动监听采用 passive listener + `requestAnimationFrame`，避免高频样式抖动。
12. **桌面反馈**：品牌图标、菜单与 CTA 使用不同强度的微动效，突出层级而非全体同时晃动。
13. **焦点可见**：沿用统一 `focus-visible`，确保键盘操作时导航与作品入口均有明确焦点。
14. **语义修复**：品牌由普通容器改为首页链接，导航继续使用原生 `nav` 与清晰的 ARIA 标签。
15. **作品可达**：Selected Works 三项由静态块改为真实链接，不再让可点击外观变成无效区域。
16. **方向提示**：作品入口加入轻量方向箭头，分别提示跳转和页内下钻。
17. **触控布局**：手机不再隐藏全部导航，只隐藏低优先级 GitHub，保留 Trace Lab 与博客入口。
18. **窄屏密度**：移动端缩小身份副标题、圆角和内边距，维持 58px 可辨识导航高度。
19. **回归防护**：校验脚本新增规则，禁止固定导航再次接入会覆盖定位的 reveal class。
20. **维护说明**：把问题根因、设计决策和断点策略写入本文档，避免后续只凭截图反复调参。

## 第三批：20 项增量优化与回归

本批按实际问题逐项处理，合并为一版发布；不是 20 个独立完整版本。

| 项 | 发现的问题 | 本次调整与验收 |
| --- | --- | --- |
| 1 | 宽屏导航对齐容器而非卡片，仍差 24px | 最大宽度改为 1232px；1440/1920px 下与 Hero 可见边缘一致 |
| 2 | 导航和身份副标题过小 | 链接 14px、副标题 12px；六个断点均可见 |
| 3 | 导航及轨迹按钮触控目标过小 | 点击高度至少 44px，浏览器尺寸检查通过 |
| 4 | 放大文字后固定导航可能盖住首屏 | 导航支持换行并观测高度；200% 字体下首屏保持在导航下方 |
| 5 | 主文案和卡片摘要低对比、手机文字偏小 | 正文与摘要统一 16px，提高浅色文字对比；桌面/手机截图复核 |
| 6 | 首屏头像动画抢注意，首屏入场可能闪烁 | 缩小头像、停止循环发光，首屏内容不先设透明；页面打开即显示 |
| 7 | 右栏文案在解释设计意图 | 改为“从这里开始”及面向访客的阅读、项目、实验说明 |
| 8 | 技术栈和标签重复，静态标签像按钮 | 去掉重复技术栈行与 Blog/Projects/Contact 装饰标签，静态标签不再位移 |
| 9 | 页面分区标题使用普通 div | 栏目标题改为 h2，保持一个 h1 |
| 10 | active / LIVE 容易误解为真实服务状态 | 导航显示技术方向；轨迹明确标注交互示意、不调用真实模型 |
| 11 | 六个节点只有四项说明且全英文 | 补全协调、规划、上下文、工具、记忆、校验；对应画布六个节点 |
| 12 | 持续动画没有暂停入口 | 新增暂停/继续；暂停后画布像素快照稳定 |
| 13 | 派发反馈弱，超过上限静默替换 | 状态区说明数量和 9 个上限，替换最早任务时明确提示 |
| 14 | 模式切换与重置缺少暂停状态约定 | 聚焦和重置均保持暂停；重置恢复 4 个任务并提示 |
| 15 | 只在加载时读取减少动态偏好 | 监听系统偏好变化并暂停；用户可主动继续，浏览器模拟验证通过 |
| 16 | 离屏/切后台依赖下一帧停止 | 立即取消帧并清理计时，恢复可见后按暂停状态决定是否继续 |
| 17 | 手机按下即派发，滑动易误触 | 抬起时判定移动距离、处理 pointercancel；真实触控事件验证轻触派发、滑动不派发 |
| 18 | 窄画布强制 280px 导致缩放，焦点会滚动内部裁切 | 采用实际尺寸，放大节点文字；外层 overflow:clip，聚焦后内部 scrollTop 为 0 |
| 19 | 卡片内容可能超出固定高度，动效对触摸/键盘不统一 | 内容自适应高度、DOM 顺序布局、明确焦点；触摸/减少动态时关闭 3D 位移 |
| 20 | 联系方式只有图标，不易发现 | 增加简短交流说明与可见邮件地址，沿用已有邮箱 |

验证：`npm run check`、`git diff --check`；Chrome 1920/1440/1024/768/390/320px 全部无页面横向溢出；12 项交互/布局断言通过，无捕获到的 JavaScript 异常。截图检查覆盖桌面首屏、手机首屏、项目卡片和轨迹场。此结果为 Chrome 回归，不代表已覆盖 Safari/Firefox。
