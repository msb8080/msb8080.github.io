# 10 篇高优先级选题清单（Q2-Q3）

## 使用规则

- P0：必须优先发布，构建主线代表作
- P1：承接主线，形成系列深度
- P2：补充视角，控制频率

---

## P0（优先发布，建议前 4 周完成 3 篇）

1. AI 后端学习路线图：从 API 调用到可扩展服务
- 类型：路线图
- 读者收益：明确阶段与能力地图
- 必含产物：阶段目标表 + 每周行动清单

2. 一次真实超时故障复盘：重试、超时、熔断如何协同
- 类型：实战复盘
- 读者收益：拿到可落地的故障处理框架
- 必含产物：故障时间线 + 排查 checklist

3. 大模型 API 生产化：SSE、超时、重试、限流与取消
- 类型：后端工程实操
- 读者收益：把一次可调用的 Demo 升级为可恢复、可观测的服务
- 必含产物：调用状态机 + 重试边界表 + Spring AI 示例

4. 后端面试答题框架：把“会做”讲成“会答”
- 类型：方法框架
- 读者收益：提升表达稳定性与结构化输出
- 必含产物：通用答题模板 + 3 个示例题

---

## P1（形成系列深度，建议 2 个月内完成）

5. 慢查询优化实战：从 SQL 画像到索引策略
- 类型：实战复盘
- 必含产物：优化前后指标对比表

6. AI 服务成本控制：Token 预算、模型路由与限流的组合拳
- 类型：方案对比
- 必含产物：成本监控指标清单

7. 项目表达模板：背景-动作-结果-复盘（附真实案例）
- 类型：方法框架
- 必含产物：可复用讲稿模板

8. AI 应用评测：Golden Set、Trace 回放与 CI 回归
- 类型：工程实践
- 必含产物：评测数据结构 + 门禁指标 + 回滚预案

## P2（副线内容，低频但稳定）

9. 技术人的复盘系统：如何做季度复盘不流于形式
- 类型：复盘方法
- 必含产物：复盘评分卡模板

10. 副业方向验证框架：从灵感清单到 MVP 决策
- 类型：研究分析
- 必含产物：方向评估矩阵 + 终止条件清单

## 发布节奏建议

- 第 1 月：1、2、4
- 第 2 月：3、5、6（不扩展 RAG 开发专题）
- 第 3 月：7、8、9（10 作为弹性位）

## 质量门槛（每篇发布前）

1. TL;DR 不超过 3 条，且可执行
2. 至少 1 张对比表或清单
3. 至少 2 条站内互链
4. 至少 1 条“风险与回滚”

## JavaGuide / AIGuide 对标后新增的储备题

这些题目吸收其“面向后端工程落地”的组织方式，但必须基于自己的实现、数据和验证重新撰写：

1. 结构化输出：JSON Schema、Function Calling 与服务端二次校验
2. 大模型网关：多 Provider 适配、模型路由、配额与降级
3. 上下文工程：规则分层、动态挂载、Token 预算与压缩策略
4. MCP Server 生产实践：Schema、权限、版本、审计与成本归属
5. Agent Loop Engineering：终止条件、检查点、失败恢复与评测
6. AI 可观测性：从一次模型调用到跨工具 Trace
7. Agent 安全：Prompt Injection、最小权限、沙箱与高危审批
